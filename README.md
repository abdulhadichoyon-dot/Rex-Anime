A premium standalone landing/bio page for RX Anime.

- Cinematic red / black / gold visual system
- Animated loader
- Responsive layout
- Smooth scroll + reveal transitions
- Interactive cursor glow
- Animated RX monogram
- Feature cards
- Marquee section
- Primary CTA opens the real RX Anime platform in a new tab
- Reduced-motion accessibility support
